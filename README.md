# DIP Diet RAG Agent — IBM Granite + Groq

A full-stack AI nutrition assistant powered by a **Dual-LLM RAG pipeline**:
- **IBM Granite 13B** (via IBM watsonx.ai) — computes DIP math & compliance
- **Groq openai/gpt-oss-120b** — formats structured, conversational responses
- **ChromaDB** — local vector store for semantic retrieval
- **Streamlit** — interactive web dashboard

## What is the DIP Diet?
The **Disciplined & Intelligent Plan** is a whole-food, plant-based nutrition system.
- Breakfast (until 12 PM): Fresh fruits — ody_weight_kg × 10 grams
- Lunch & Dinner Plate 1: Raw vegetables — ody_weight_kg × 5 grams (must finish before Plate 2)
- Dinner: Strictly before 8:00 PM

## Project Structure
`
.
+-- dip_knowledge.txt   # Structured DIP Diet knowledge base
+-- ingest.py           # Ingests knowledge ? ChromaDB vector store
+-- agent.py            # Dual-LLM pipeline (Granite ? Groq)
+-- app.py              # Streamlit dashboard
+-- requirements.txt    # Python dependencies
+-- chroma_db/          # Auto-generated by ingest.py (not committed)
`

## Setup & Run

### 1. Install dependencies
`ash
pip install -r requirements.txt
`

### 2. Configure environment
Create a .env file:
`env
GROQ_API_KEY=your_groq_api_key
GROQ_BASE_URL=https://api.groq.com/openai/v1
MODEL_NAME=openai/gpt-oss-120b

# Optional — for IBM Granite
IBM_WATSONX_APIKEY=your_ibm_apikey
IBM_WATSONX_PROJECT_ID=your_project_id
IBM_WATSONX_URL=https://us-south.ml.cloud.ibm.com
`

### 3. Build the vector store
`ash
python ingest.py
`

### 4. Launch the app
`ash
streamlit run app.py
`
Open http://localhost:8501

## Features
- **Tab 1 — Conversational Assistant**: Ask anything about DIP Diet; get personalised gram targets
- **Tab 2 — Visual Meal Plan**: Auto-calculated meal cards for your body weight
- **Sidebar**: Live fruit (kg×10g) and veggie (kg×5g) targets with health condition input
